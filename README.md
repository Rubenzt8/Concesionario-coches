# Concesionario de Coches 🚗

Aplicación de gestión de concesionario desarrollada en Java, que permite registrar y consultar coches de distintos tipos mediante un menú interactivo por consola.

## Conceptos aplicados

- Clase abstracta (`Coche`) con atributos, getters/setters y `toString`
- Herencia: `CocheKm0`, `CocheNuevo`, `CocheSegundaMano`
- Interfaces: `Vendible` y `Alquilable`
- Atributo de clase estático (`numCochesStock`)
- Colecciones con `ArrayList`
- Entrada de datos por consola con `Scanner`

## Tecnologías

- Java
- IntelliJ IDEA

## Cómo ejecutarlo

1. Clona el repositorio
2. Abre el proyecto en IntelliJ IDEA
3. Ejecuta `Concesionario.java`
4. Sigue el menú interactivo en consola
